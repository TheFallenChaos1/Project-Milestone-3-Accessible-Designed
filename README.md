# My Portfolio

A modern responsive portfolio built with HTML and CSS.

## Accessibility Fixes
- Added proper labels to every form input
- Used fieldset and legend on the contact form
- Added clear error messages for empty required fields
- Checked all text and background colors for WCAG AA contrast

## Gestalt Principles
- **Proximity**: Skill cards and project cards are grouped closely so they feel related
- **Similarity**: All cards use the same background, border, and hover style for consistency

## Color Palette
Dark background with teal and coral accents used consistently across every page.
